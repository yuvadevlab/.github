## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information exposure within any repository in the Yuva DevLab organization, please **do not** open a public issue.

Please report vulnerabilities privately by emailing:

📧 **yuva.devlab@gmail.com**

Include:

- The affected repository or package name.
- Description of the vulnerability and attack vector.
- Minimal steps to reproduce or proof-of-concept.

All valid reports will be acknowledged and remediated promptly.
